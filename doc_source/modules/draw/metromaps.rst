Metro interleaving maps
=======================

The ``metromaps`` functions draw the vertex and edge maps of a fitted
``Interleave`` object, with matching colors for source edges and their images.
Edges can be colored individually or grouped by source branch.

A full example can be found in the `Metro Interleaving Maps Jupyter Notebook <../../notebooks/metro_interleaving_maps.ipynb>`_.
